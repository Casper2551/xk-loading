* **Installation**
Before proceeding with the installation, please take note of the following important points:

**IMPORTANT: If you plan on importing a YouTube video that has been converted from a third-party website, be aware that there are known issues with HTML video tags that may result in incorrect video display.**
**IMPORTANT: Ensure that you rename your logo and video files in the "assets" folder to match the corresponding HTML file. Also, remember to save the logo file in .svg format.**

* **Key Features**
XK-Loading offers the following key features:

- Seamless loading experience
- Customizable logo
- Configurable video background overlay
- Adjustable loading bar
- Separate audio configuration
- Custom volume control
- Music control guide bar
- Color Gradient
- For creating CSS color gradients, you can use the CSS Color Gradient Overlay Generator available at: https://cssgradient.io/
